# 株式会社Resonary コーポレートサイト

株式会社Resonaryの会社案内サイト。HTML・CSS・JavaScriptのみで動作します。

## GitHub Pages

リポジトリの Settings → Pages で、Source を「Deploy from a branch」、Branch を `main`、フォルダーを `/ (root)` に設定してください。ビルドは不要です。

すべてのページ・画像は相対パスを使っており、プロジェクトサイトでそのまま表示できます。

## ページ

- `index.html`：トップページ
- `company.html`：会社概要
- `business.html`：事業内容
- `news.html`：お知らせ
- `careers.html`：採用情報
- `contact.html`：お問い合わせのプレビュー
- `privacy.html`：個人情報の取り扱い（準備中）
